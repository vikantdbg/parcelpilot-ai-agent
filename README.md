# ParcelPilot AI Support Agent

AI support and operations agent for the CalQuity AI Engineer take-home assessment.

## Run

Install dependencies with `pip install -r requirements.txt`, add `OPENAI_API_KEY` to `.env`, then run `streamlit run app/main.py`.

The project includes PDF retrieval, structured Excel lookup, customer account scoping, confirmation-gated escalation actions, architecture/product notes, and assessment test cases.
